A simple shared board inside WordPress.

== Description ==
One board with draggable cards, custom columns, one category and assignee per card, comments, and image attachments. A card opens in an overlapping side panel. Existing card edits save when the panel closes. Status buttons, inline category editing, an image lightbox, and the WordPress media selector keep the work inside the board. Select existing WordPress users in Settings; site administrators always have access.

Comment images use the standard Media Library. Folderino is optional: when active, choose a media folder in Boardino Settings. On a fresh installation with Folderino active, a Boards folder is created or reused. Without Folderino, images still upload normally. Changing the folder affects new uploads only.

Cards and comments stay in WordPress. Deactivating Boardino preserves all data. Archived cards can be restored. No data is removed on uninstall.

== Installation ==
1. Upload boardino.zip through Plugins > Add Plugin > Upload Plugin.
2. Activate Boardino.
3. Open Boardino > Settings to select people and categories.
4. Open the board and add your first card.
